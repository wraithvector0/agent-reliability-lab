# Agent Reliability Lab

Experimental laboratory for studying reliability patterns in autonomous AI systems.

## Versions

### v1-manual-orchestrator
Manual orchestration using:
- retries
- JSON validation
- escalation flows
- deterministic control logic

### v2-langgraph-orchestrator
Planned migration to LangGraph-based orchestration with:
- graph execution
- stateful workflows
- conditional routing
- durable execution

## Focus Areas

- agent reliability
- orchestration
- runtime safety
- autonomous systems
- deterministic execution
